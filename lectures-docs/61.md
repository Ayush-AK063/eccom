## 2. Overall Flow

```
User "Login with Google" click karta hai
   ↓
signInWithPopup(auth, googleProvider)  → Google popup
   ↓
Firebase user milta hai → result.user.getIdToken()
   ↓
POST /api/user/google-login  { idToken }
   ↓
Backend: admin.auth().verifyIdToken(idToken)   (Firebase Admin SDK)
   ↓
Email se User find karo → nahi mila to naya user create (no password)
   ↓
generateAccessToken + generateRefreshToken
   ↓
Response → frontend localStorage mein tokens, context.setUserData, setIsLogin(true)
   ↓
Redirect to "/"
```

## 3. Firebase Console Setup

1. console.firebase.google.com par project banao.
2. **Authentication → Sign-in method → Google** enable karo.
3. **Project settings → Your apps → Web app** add karo, config (apiKey, authDomain, projectId, appId) copy karo.
4. **Authentication → Settings → Authorized domains** mein `localhost` (aur baad mein production domain) hona chahiye.
5. Backend ke liye: **Project settings → Service accounts → Generate new private key** → JSON se `project_id`, `client_email`, `private_key` lo.

## 5. Firebase Config File (`my-project/src/firebase.js`)

```js
import { initializeApp } from "firebase/app";
import { getAuth, GoogleAuthProvider } from "firebase/auth";

const firebaseConfig = {
  apiKey: import.meta.env.VITE_FIREBASE_API_KEY,
  authDomain: import.meta.env.VITE_FIREBASE_AUTH_DOMAIN,
  projectId: import.meta.env.VITE_FIREBASE_PROJECT_ID,
  appId: import.meta.env.VITE_FIREBASE_APP_ID,
};

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);
export const googleProvider = new GoogleAuthProvider();
```

## 6. Login Page — Google Button Handler

```js
const handleGoogleLogin = async () => {
  try {
    setIsGoogleLoading(true);
    const result = await signInWithPopup(auth, googleProvider);
    const idToken = await result.user.getIdToken();

    const res = await postData("/api/user/google-login", { idToken });

    if (res?.error !== true) {
      localStorage.setItem("accesstoken", res?.data?.accessToken);
      localStorage.setItem("refreshtoken", res?.data?.refreshToken);
      context.setUserData(res?.data?.user);
      context.setIsLogin(true);
      context.openAlertBox("success", "Logged in with Google!");
      history("/");
    } else {
      context.openAlertBox("error", res?.message || "Google login failed");
    }
  } catch (error) {
    context.openAlertBox("error", error?.message || "Google login failed");
  } finally {
    setIsGoogleLoading(false);
  }
};
```

Points:
- `isGoogleLoading` se button disable + loader dikhta hai, double-click se bachav.
- Popup user band kar de to `catch` mein error aata hai (`auth/popup-closed-by-user`).

## 8. Backend — Firebase Admin Init

```js
import admin from "firebase-admin";

if (!admin.apps.length) {
  admin.initializeApp({
    credential: admin.credential.cert({
      projectId: process.env.FIREBASE_PROJECT_ID,
      clientEmail: process.env.FIREBASE_CLIENT_EMAIL,
      privateKey: process.env.FIREBASE_PRIVATE_KEY?.replace(/\\n/g, "\n"),
    }),
  });
}
```

`.replace(/\\n/g, "\n")` zaroori hai kyunki `.env` mein private key ke newlines `\n` text ki tarah aate hain.

## 9. Backend — `googleLoginController`

1. `idToken` body se lo, na ho to 400.
2. `admin.auth().verifyIdToken(idToken)` → `{ name, email, picture, uid }`.
3. `User.findOne({ email })`
   - Nahi mila → naya user: `googleId`, `loginWithGoogle: true`, `verify_email: true`, `avatar: picture`, `status: "active"`.
   - Mila → `googleId` set karo agar pehle nahi tha.
4. Status `active` nahi to 400.
5. Access/refresh token generate, `last_login_date` update, cookies set.
6. `{ accessToken, refreshToken, user }` return.

Route: `userRoute.post('/google-login', googleLoginController);`

> **Kyun frontend ka data seedha trust nahi karte?** Agar frontend sirf email bheje to koi bhi kisi ka email bhej kar login kar sakta hai. Isliye ID token server par Firebase Admin se verify hota hai.

## 10. Common Errors

| Error | Reason |
|---|---|
| `auth/unauthorized-domain` | Firebase authorized domains mein localhost/domain nahi |
| `auth/popup-blocked` | Browser ne popup block kiya |
| `auth/configuration-not-found` | Google sign-in method enable nahi |
| `Failed to parse private key` | `FIREBASE_PRIVATE_KEY` mein `\n` replace nahi hua / quotes galat |
| `Firebase ID token has incorrect "aud"` | Frontend aur backend alag Firebase projects use kar rahe hain |

### Audit mein mile issues
1. **Password hash response mein leak:** controller pura `user` document bhejta hai. Agar existing user (jiska password hai) Google se login kare to bcrypt hash frontend tak jaata hai. `user.password` hata kar bhejna chahiye (ya schema mein `select: false`).
2. Existing email user Google se login kare to `verify_email` true nahi hota — agar wo unverified tha to bhi login ho jaata hai (Google ne email verify kiya hai, to set kar dena chahiye).
3. Cookies `secure: true` hain — localhost (http) par browser kuch cases mein cookie set nahi karega; app localStorage token use karta hai isliye abhi kaam chal jaata hai.
