## 5. Loading State ka Use

Product details API ko response dene mein kuch time lag sakta hai. Is duration mein screen par blank content dikhane ke bajay loader show kiya jaata hai.

Loading state ka conceptual example:

js

const = useState(true);


Yahan:

- `loading` current loading status store karta hai.

- `setLoading` loading status change karta hai.

- Initial value `true` rakhi ja sakti hai, kyunki page open hote hi API request start hoti hai.

Conditional rendering:

jsx

{loading ? (

  <Loader />) : (

  <ProductDetailsContainer />)}


Iska matlab:

- Agar `loading` true hai, to loader render hoga.

- Agar `loading` false hai, to product details container render hoga.

Video mein isi condition ke through loader aur product content ko control kiya jaata hai.

## 10. Promise Chain ka Working

Video mein response ke baad `.then()` ka use karke agla data process kiya jaata hai.

Promise chain ka basic pattern:

js

someApiCall()

  .then((response) => {

return anotherApiCall(response.categoryId);

})

  .then((response) => {

console.log(response);

})

  .catch((error) => {

console.log(error);

});


Is flow mein:

1. First API call execute hoti hai.

2. First response receive hota hai.

3. Response se category ID read hoti hai.

4. Category ID second API call ko pass hoti hai.

5. Second response receive hota hai.

6. Final data process hota hai.

Agar kisi bhi stage par error aaye, to `.catch()` error ko handle kar sakta hai.

## 17. `props.userId` Undefined Hone ka Reason

Agar `props.userId` undefined aa raha ho, to possible reasons:

- Child component ko wrong component render kiya gaya hai.

- Initial render par user ID empty hoti hai.

- Parent state update hone se pehle child render ho gaya.

- Conditional rendering missing hai.

  <Review userId="userId" />)}

## 18. Data Length Condition

Video mein ek condition lagayi jaati hai:

js

data.length !== 0


Is condition ka purpose hai ki jab tak data empty hai, tab tak dependent component ya operation execute na ho.

Example:

jsx

{data.length !== 0 && (

  <ProductDetails data="{data}" />)}


Iska meaning:

- Agar `data.length` zero hai, to product details render nahi hongi.

- Agar `data.length` zero se different hai, to product details render hongi.

Yeh condition useful hoti hai jab API response array format mein aata hai.

Agar response object format mein ho, to condition different ho sakti hai:

jsx

{productData && (

  <ProductDetails data="{productData}" />)}


Ya:

jsx

{Object.keys(productData).length !== 0 && (

  <ProductDetails data="{productData}" />)}
