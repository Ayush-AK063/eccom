2. Shared Cart State ka Use

Video ke transcript mein setCartData ke through cart state ko update karne ka reference milta hai. Isse pata chalta hai ki cart data ek shared state ya context se manage ho raha hai.

Cart data ko context mein rakhne ka main reason yeh hai ki application ke different components same cart information use kar saken:

Header cart icon cart items ya count dikha sake.

Product item component check kar sake ki product already cart mein hai ya nahi.

Cart panel actual cart items render kar sake.

Logout ke time cart state clear ki ja sake.

Quantity update ya delete ke baad poori application mein latest cart data reflect ho.

Agar cart data sirf ek single component ke andar store kiya jaaye, to baaki components mein updated information automatically nahi pahunchti. Shared context se ek central cart state maintain hoti hai.

Typical state structure kuch is type ka ho sakta hai:

const = useState([]);

Yahan:

cartData current cart items ko represent karta hai.

setCartData cart items ko update karta hai.

3. Logout ke Baad Cart Data Clear Karna

Transcript mein logout functionality ke andar context.setCartData ko blank value dene ka step clearly mention hua hai. Iska purpose logout hone ke baad previous user ka cart data screen par visible rehne se rokna hai.

Logout function ke andar cart data clear karne ka flow:

const logout = () => {

  // user logout logic

  context.setCartData([]);

};

Yahan [] empty array ka meaning hai ki current user ke liye frontend cart state mein koi item nahi hai.

Yeh step kyun zaroori hai

Agar logout ke baad cartData clear nahi kiya jaata, to yeh problems aa sakti hain:

Previous user ke cart items next screen par dikh sakte hain.

Header mein purana cart count remain kar sakta hai.

UI aur logged-in user ke actual database cart ke beech mismatch create ho sakta hai.

Transcript ke according setCartData ek array state hai, isliye logout ke time usse empty array par set kiya jaata hai. Iske baad refresh karke dobara login kiya jaata hai, jisse verify kiya ja sake ki logout ke baad cart state properly reset ho rahi hai.

11. Quantity Update Function ka Structure

Cart item ki quantity change karne ke liye ek common function banaya ja sakta hai jo increase aur decrease dono operations handle kare. Is function ko current cart item, operation type aur item ki existing quantity milti hai.

const updateQuantity = async (item, action) => {

  let newQuantity = item.quantity;

  if (action === "increase") {

    newQuantity = item.quantity + 1;

  }

  if (action === "decrease") {

    newQuantity = item.quantity - 1;

  }

  if (newQuantity <= 0) {

    await removeCartItem(item._id);

  } else {

    await updateCartItem(item._id, newQuantity);

};

Is function mein pehle current quantity read hoti hai. Agar action increase hai, to quantity mein 1 add hota hai. Agar action decrease hai, to quantity mein se 1 subtract hota hai. New quantity calculate hone ke baad decide kiya jaata hai ki update API call karni hai ya delete API call.

const quantityValue = Number(event.target.value);

if (!Number.isInteger(quantityValue)) {

  return;

}

if (quantityValue < 1) {

  removeCartItem(item._id);

  return;

}

updateCartItem(item._id, quantityValue);

Validation ka purpose:

Empty value ko prevent karna.

Decimal quantity ko prevent karna.

Negative quantity ko prevent karna.

Zero quantity par remove logic execute karna.

String value ko number mein convert karna.

Button-based implementation mein user sirf fixed increment ya decrement karta hai, isliye invalid input ka chance kam hota hai.

36. Duplicate Request ko Handle Karna

Agar user Plus ya Minus button ko rapidly multiple times press karta hai, to multiple API requests ek saath ja sakti hain. Isse responses wrong order mein return ho sakte hain.

Button temporarily disable karne ka pattern:

<button

  disabled={updating}

  onClick={() => updateQuantity(item, "increase")}

>

  +

</button>

Function:

const updateQuantity = async (item, action) => {

  setUpdating(true);

  try {

    const newQuantity =

      action === "increase"

        ? item.quantity + 1

        : item.quantity - 1;

    await updateCartItem(item._id, newQuantity);

    await refreshCartItems();

  } finally {

    setUpdating(false);

  }

};
