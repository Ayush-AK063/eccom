# 2026-11-19

## 1. "Remember me" — admin + store dono pe asli kaam

**Pehle kya tha:** admin pe checkbox sirf email yaad rakhta tha; login hamesha same (localStorage), aur 5 ghante (access token) baad sab logout — kyunki refresh-token API thi par koi app use call nahi karta tha. Store pe checkbox hi nahi tha. Server refresh token ko DB se match nahi karta tha (logout ke baad bhi chalta) aur suspended user ko bhi naya token deta tha.

**Ab:**
- Server: `generateRefreshToken(userId, remember)` → tick = 30 din, warna 1 din. Email + Google login `remember` lete hain. `refresh-token`: header se token, DB wale se match (logout = revoke), suspended → 403, naya access token. `auth` middleware ab header pehle dekhta hai (refresh ke baad naya token), cookie baad mein.
- Dono apps: `utils/session.js` — `saveSession(access, refresh, remember)`, `clearSession`, `checkBrowserSession` (main.jsx mein; remember OFF + browser band → logout, session cookie `liveSession` se), `refreshAccessToken` (ek saath ek hi call), axios interceptor + `postData` mein 401 pe chupchaap refresh aur retry (login / register / reset wale URL chhod ke; network error pe tokens nahi hatate).
- Admin login: Remember me default ON, "stay signed in for 30 days", OFF pe email bhi yaad nahi. Store login: naya checkbox (email + Google dono pe lagu). Google signup (register page) = remember.
- Note: ek user ka ek hi refresh token (DB) → naye device pe login karne se purane device ka "remember" khatam (access token expire hone par logout).
- Test: galat refresh token → 401 "Session expired". Asli login ke saath test nahi kiya.
